# 💠 Project: Sparky
* **Наименование:** Плагин Sparky является цифровым аватаром автора, воплощая принципы инженерного мышления, ленинско-коммунистического мировоззрения и созидательной философии, отраженные в персонаже Искра. Он ориентирован на реальный результат, структуру и полезное действие в кодовой базе.
* **Предыдущее(рабочее) наименование:** CrazyGerman. Это не «немец». Производная от ника **AlexCRAZY74** и имени **Герман**, которое придумано для ИИ Gemini.
* **Концепция:** Автономная экосистема для NetBeans, объединяющая интеллектуального помощника с итерационным сбором контекста, принудительным резервированием изменяемых данных и ведением проектных решений через JSON.

---

## 🏗 1. Архитектурный "Триумвират" и инструменты (Core)
Система строится на принципе слабой связности через интерфейсы и универсальные структуры данных.

* **`BrainHandler` (Процессор):** Центральный узел. Поддерживает итерационные запросы к ИИ, анализирует поле `needs`, доставляет запрашиваемые ресурсы (включая структуру проекта и вкладки IDE) и управляет жизненным циклом ответа.
* **`ProjectHandler` (Завхоз):** Управляет контекстом в `.sparky/`. Включает в себя **`BackupManager`** для зеркалирования изменений.
* **`AppConfig` (Управление конфигурацией):** Двухслойная система чтения настроек (UserData из JSON приоритетнее SystemData из среды IDE).
* **`aiModelHandler` (Диспетчер моделей):** Класс-диспетчер для динамического управления конфигурациями моделей и провайдеров ИИ в зависимости от настроек проекта и активной сессии.
* **`StoredNotes` (Контекстная память и Аудит):** Заменил старый жесткий профиль. Компонент долгосрочной памяти на базе `Storage`. Ведет историю изменений (аудит) личности пользователя и контекста, сохраняя данные в `user_profile.json` и файлы проекта.
* **`Storage` (Универсальное хранилище):** Обертка над `Map<String, Object>` для навигации через слэш-пути. Базовый класс для `SessionNode`.
* **`JSBridge` (Двусторонний мост):** Связь Java <-> WebView (JSON-строки).

## 🔄 2. Протокол итерационного взаимодействия
Вместо одного запроса используется цикл «уточнения», позволяющий ИИ запрашивать нужные файлы и ресурсы среды.

* **`stages`:** Массив объектов для визуализации прогресса в UI (статусы: `wait`, `process`, `done`).
* **`needs`:** Список ресурсов (`file://...`, `ide://...`), которые ИИ запрашивает у среды в процессе выполнения задачи.
* **`payload`:** Контейнер, в который IDE упаковывает содержимое запрошенных ресурсов и возвращает ИИ.
* **`profile_update`:** Механизм обратной связи. Если ИИ включает этот блок в ответ, `BrainHandler` перехватывает его и обновляет долгосрочную память через `StoredNotes`.

## 🛡️ 3. Система резервного копирования (Total Shadow Backup)
Бескомпромиссная защита кода от деструктивных действий ИИ или сбоев системы.

* **Локация:** `.sparky/.backup/` внутри проекта (прописан в `.gitignore`).
* **Триггер:** Вызывается вручную через контекстные меню (`BackupAction`) или автоматически **ДО** того, как данные попадут в `payload` или будут изменены.
* **Хранение:** Копирование файлов с сохранением структуры каталогов проекта. Версионность обеспечивается за счет человекочитаемых расширений формата `.имя_файла.расширение.yyyy-MM-dd_HH-mm-ss.bak`.

## 🖼 4. UI Layer (Nodes API & WebView)
* **`NodeProject`:** Визуальный узел проекта в дереве NetBeans.
* **`TaskListTopComponent`:** Панель-навигатор со списком открытых проектов.
* **`ChatTopComponent`:** JavaFX `WebView`. Отрисовывает чат и список `stages`. Поддерживает динамическое применение темы IDE через CSS-переменные.
* **`handler_chat.js`:** Логика фронтенда, динамическое построение DOM чата, поддержка Markdown.

## 📁 5. Файловая структура (Data Layer)

### Глобальные данные (NetBeans User Dir):
```text
config/crazy_sparky/
├── user_profile.json    # Долгосрочная память (настройки личности, факты)
└── settings.json        # Настройки плагина (глобально)
```

### Локальные данные (.sparky/):
```text
PROJECT.md               # Архитектура и статус (этот файл)
.sparky/
├── project_map.md       # Ментальная карта и структура задач
├── trainers.json        # Индекс доступных файлов-тренеров
└── .backup/             # Человекочитаемые теневые копии исходников (*.yyyy-MM-dd_HH-mm-ss.bak)
```

## 📦 6. Технологический стек

* **Язык:** Java 21 / JavaFX 21.
* **Парсинг:** **Flexmark** (Markdown) и **GSON** (JSON).

* **Связь:** `executeScript` (Java -> JS) + `JSBridge` (JS -> Java).
* **Визуализация:** **jsMind** / **MindElixir** для интерактивных ментальных карт внутри WebView.
